# Contributing to Tattoo Needle Selector

Thank you for your interest in contributing to the Tattoo Needle Selector! This tool is part of the Poli International Widget Suite, built for the body art community.

## 🛠️ Development Setup

1. **Fork and clone the repository**

   ```bash
   git clone https://github.com/Poli-International/needle-selector.git
   ```

2. **No Build Process**
   This tool is built with pure HTML/CSS/JS. Open `index.html` in your browser to test.
