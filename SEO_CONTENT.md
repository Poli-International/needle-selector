## What is Tattoo Needle Selector?

The Tattoo Needle Selector is a free interactive web tool that helps tattoo artists choose the optimal needle configuration for their specific tattoo style, technique, detail level, and skin type. Built on a comprehensive database of 25+ needle configurations across five categories (Round Liner RL, Round Shader RS, Magnum M1, Curved Magnum CM, and Flat F), the tool provides instant recommendations with visual SVG diagrams showing needle arrangement patterns.

The tool includes four main functions:
1. **Quick Selector** - Form-based recommendation engine that filters by style, technique, detail, and skin
2. **Needle Code Decoder** - Input any needle code to get complete specifications, best uses, and settings
3. **Comparison Mode** - Compare 2-3 needle configurations side-by-side
4. **Reference Chart** - Complete catalog of all needle types with expandable details

Each recommendation includes needle count, configuration type, pattern description, coverage diameter, best uses, recommended voltage range, machine speed, penetration depth, pro tips, and alternative options. The tool also generates real-time SVG diagrams showing the physical arrangement of needles in each configuration.

## Frequently Asked Questions (FAQ)

### Q1: What does the needle code "9RL" mean?
**A:** The code breaks down as: "9" = 9 needles, "RL" = Round Liner configuration. This indicates a tight round grouping of 9 needles, approximately 1.6mm in diameter, ideal for bold outlines and traditional tattoos.

### Q2: How do I know which detail level to choose?
**A:** Select "Fine" for micro-detail work like portraits and fine line script, "Medium" for most general tattoo work, and "Bold" for traditional, tribal, and cover-up work. The tool adjusts needle count and configuration accordingly.

### Q3: What is the difference between Round Liner (RL) and Round Shader (RS)?
**A:** RL needles have a tight round configuration for precise line work. RS needles have a looser round configuration that allows more ink flow and softer edges, making them better for shading and color blending.

### Q4: Can I use this tool for bugpin needle selection?
**A:** Yes. The tool's database includes all standard needle diameters. Bugpin needles (thinner diameter #10 or #08) are represented in the fine detail recommendations, particularly for realism and portrait work.

### Q5: What voltage should I use with a 9RL needle?
**A:** The tool recommends 8.0-9.5V for 9RL needles, with medium to fast machine speed and 1.5-2.0mm penetration depth. Adjust based on your machine type and personal technique.

### Q6: Why does the tool ask for skin type?
**A:** Skin thickness affects needle penetration and trauma. Thin skin (inner arm, wrists) requires smaller needles and lower voltage. Thick skin (back, shoulders) can handle larger configurations and higher voltage.

### Q7: What is a Curved Magnum (CM) needle?
**A:** CM needles have needles arranged in a curved line pattern, creating a softer, more gradual ink deposit than flat magnums. They are preferred for portrait shading and smooth color blending.

### Q8: How many needle configurations are in the database?
**A:** The tool includes 25+ needle configurations across 5 categories: Round Liners (1RL-14RL), Round Shaders (5RS-11RS), Magnums (5M1-15M1), Curved Magnums (7CM-11CM), and Flats (7F-15F).

### Q9: What if my style/technique combination has no recommendation?
**A:** The tool uses fallback logic. If no exact match exists, it defaults to the lining recommendation for that style. You can also use the Decoder to explore individual needle types.
